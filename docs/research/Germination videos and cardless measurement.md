# Published petri dishes can carry Argus's demo

Argus can skip the multi-day bean run and still show a real long experiment. The **Genze & Grimm germination dataset** on Mendeley Data (**CC BY 4.0**, one 840 MB zip, no login) holds **247 top-down 85 mm petri dishes** of maize, rye and pearl millet, 6–12 seeds each, photographed **every 30 minutes for about 48 hours**, with a human-drawn "germinated / not germinated" box on every seed in every frame. No other public source offers all four things Argus needs: several vessels, a known-size object that replaces the card, more than two replicates per condition, and ground truth that can score Argus's own calls. Its weakness is the experimental design. The conditions are species, not salt or temperature, and **no openly licensed dataset or video found anywhere films treated and control vessels side by side with replicates**, so the hypothesis has to be about species and the run has to be labelled a re-analysis of published data. Measuring without the card works when a known object lies in the measured plane: the dish rim gives about ±3–5 %, whereas monocular depth models only place most pixels within 25 % of true depth and must stay out of verdicts; for footage with no reference at all, pixel units and "percent of first frame" are normal practice in established tools. CC0 and CC BY sources need only attribution, CC BY-SA Commons clips add share-alike duties, and standard-licence YouTube videos are off limits without written permission. **Recommendation:** download Genze today and make it the long-run backbone; before Nov 4, build an image-sequence importer that records where data came from, an automatic dish ruler with honest uncertainty, a relative pixel mode and a ground-truth check; keep Argus's own salt run only if it can start tonight, because only that run can show a dose-response and a numeric next-run suggestion.

## Genze's 247 labelled dishes beat every other public source

The research covered GitHub phenotyping tools, Hugging Face, Mendeley Data, Zenodo, figshare, journal supplements and Wikimedia Commons. Only two germination sets can be downloaded today under a clear open licence, and one non-germination set is the only public match for Argus's control-versus-treatment design.

Genze fits the existing `seed-germination` recipe almost exactly. A Raspberry Pi camera about 40 cm above a 4×3 grid of dishes on black cloth gives the fixed, top-down, plain-background view Argus was designed for ([Mendeley Data v3](https://data.mendeley.com/datasets/4wkt6thgp6/3)). Each dish holds 6–12 seeds ([Genze et al. 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7754596/)), under the 16-object cap that SAM 3.1's video mode hit in Argus's own probe ([KB 04](../knowledge-base/04-models-and-api.md)), so every seed can be its own track. A seed counts as germinated once its radicle visibly emerges, and the boxes on all **23,797 images** give a per-dish germination curve to set against Argus's sprout calls ([Genze et al. 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7754596/)). The paper describes each dish as a 624 × 624 px crop, which with the 85 mm diameter works out to roughly **0.14 mm per pixel**, so Argus's 2 mm sprout threshold spans about 14 pixels: coarse, but enough (my calculation, not a published figure). Three things need checking on download: whether the zip holds full 4×3 frames or only per-dish crops, how file names encode dish and experiment, and whether each 12-dish run held a single species. The per-species counts (82, 81 and 84, about seven grids each) suggest each run held one species, in which case a maize-versus-rye mosaic is a montage of separate runs, and Argus's rival-explanation check should name the run date as a possible cause rather than hide it. The authors also dropped series in which dishes dried out ([PMC7754596](https://pmc.ncbi.nlm.nih.gov/articles/PMC7754596/)).

**ChronoRoot** is the strongest second source and the only CC0 one, so a downsampled run can go into the public repo freely ([HF card](https://huggingface.co/datasets/ngaggion/UnsupervisedRootVideos)). Its `Germination` folder holds 32 infrared plates, and each Raspberry Pi module images four plates at the same timestamps, so cameras 1–4 tile into a genuine one-rig 2×2 view. One four-plate run is about 0.94 GB of timestamp-named PNGs, while the whole repository is 228 GB, so fetch a single run by path pattern ([HF file listing](https://huggingface.co/api/datasets/ngaggion/UnsupervisedRootVideos/tree/main/ArabidopsisDataset/Germination)). The paper publishes a scale of about **0.04 mm per pixel** on roughly 12 cm plates ([ChronoRoot 2.0](https://arxiv.org/html/2504.14736v2)), which lets the demo show Argus's plate-edge scale agreeing with an independent published one. Three limits keep it out of the verdict. Frames are infrared greyscale, so colour readings mean nothing; the screening tool tracks up to 100 seeds per plate ([chronoroot.github.io](https://chronoroot.github.io)), far beyond the 16-object video cap; and folder names carry only module, date and camera, so which plate got which genotype or light regime is unknown. Nobody has opened a frame from this folder yet.

**ColTapp**'s *Staphylococcus aureus* plate timelapses are the only public set found with Argus's exact design: **8 control and 14 rifampicin plates**, one frame every 10 minutes for about 70 hours, at a published 25 or 50 µm per pixel ([Bär et al. 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7528005/)). The data are CC BY 4.0 and zipped per plate, so two controls and two treatments cost about 3.1 GB ([figshare record](https://api.figshare.com/v2/articles/12951152)). It remains a stretch target rather than the backbone. Plates carry 16 to 1,509 colonies, which SAM's video mode would truncate at 16; the Canon series shot one plate per frame, so a grid would be a montage; whether rifampicin sat in the agar or was a pre-exposure is unconfirmed; Argus has no colony recipe yet; and a pathogen experiment is a poor stage for Argus suggesting the next run.

The famous germination platforms fail on availability, not quality. SeedGerm's repository has neither example data nor a LICENSE file ([GitHub](https://github.com/Crop-Phenomics-Group/SeedGerm)), SPIRO's assay code is BSD-2 but ships no data licence ([SPIRO.Assays](https://github.com/jiaxuanleong/SPIRO.Assays)), and the SPENCER robot has no public image deposit ([bioRxiv](https://www.biorxiv.org/content/10.1101/2024.05.10.593629.full.pdf)). The closest scientific match to Argus's salt plan, a licorice study with **16 NaCl levels** imaged every 15 minutes for 120 hours, offers its data only on request ([Frontiers 2024](https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2024.1474321/full)), too slow for Nov 4. Tomato salt-stress root data exists only as CSV traces ([Zenodo 10957050](https://zenodo.org/records/10957050)), useful as published reference numbers but impossible to import, and the Aberystwyth Arabidopsis set, which has harvest ground truth, ships its images as one 61.6 GB zip ([Zenodo 168158](https://zenodo.org/records/168158)).

### Species, not salt, must carry the hypothesis

Because no public footage combines a treatment with replicates, the demo must not relabel Genze dishes or ChronoRoot plates as "0 / 50 / 100 mM NaCl"; that would invent evidence, which Argus's own rules forbid. The honest framing treats species as conditions, picks three or four dishes per species, and predicts a difference in time to 50 % germinated between two species. That meets "at least 2 replicates per condition" and adds a real accuracy figure from the boxes. Preregistration is the harder problem. Argus counts a plan only if it was locked before the run began, and judges an import against its real recording start when one is given ([KB 15, D-67 and D-69](../knowledge-base/15-decisions-log.md)), a bar that a dataset recorded years ago, with a published paper, can never meet. Locking the plan before importing, and before reading the paper's per-species curves, keeps the analysis blind to Argus's own numbers. The verdict should still say plainly that this is a **retrospective re-analysis** instead of collapsing to Too early, which means something else. That label is itself a strong demo moment: Argus refusing to overclaim on found data is exactly the rigour judges should see. What Genze cannot show is a dose-response view, which needs a numeric factor with three or more levels ([KB 15, D-49](../knowledge-base/15-decisions-log.md)), or an Ax suggestion for the next salt levels.

## The dish is a ±3–5 % ruler; depth models are not

The only cardless route to about 1 % scale error is a known object in the same plane as the subject. Automatic ruler reading has only recently become reliable: **RulerNet** reaches a mean error of **1.19 % and 1.31 %** on two in-the-wild benchmarks, while the classic tick-frequency method averages **14.79–62.11 %** and digit-reading OCR 56.71–76.05 % ([RulerNet](https://arxiv.org/html/2507.07077)). RulerNet's code and weights carry no stated licence yet ([repo](https://github.com/ymp5078/RulerNet)), which rules it out before Nov 4.

A petri dish makes a decent ruler if its uncertainty is recorded honestly, because "90 mm" is nominal. SPL lists its 90 mm lid at **92.40 mm** ([SPL datasheet](https://www.n-genetics.com/files/co/Documents/technicaldata/spl_19477.pdf)), one glass 90 mm dish has a lid of 90 ± 1.0 mm but a **base of 84 ± 1.0 mm** ([Findel](https://findel-international.com/product/science/biology/microbiology/glass-petri-dish-90x15mm-pack-of-10/e8a77215)), and Integra uses about 90.5 mm as its reference ([Integra](https://www.integra-biosciences.com/sites/default/files/documents/oi_mj_petri_dish_compatibility_list_v21.pdf)). That is ±2–3 % between makers, plus a 7 % trap if lid and base are confused. Seeds also sit below the rim: content Δh below it, seen from a top-down camera at distance Z, images at scale (Z+Δh)/Z, so 8 mm of depth costs about 2.7 % at 300 mm and about 5 % at 160 mm (geometry, not a measured figure). Together these give the **±3–5 %** total. A tilted dish images as an ellipse whose major axis keeps the scale, and whose minor/major ratio is a free tilt warning. A bank-format card is the better pocket reference, at **85.60 × 53.98 mm** with tolerances of about 0.1 mm ([ISO/IEC 7810](https://en.wikipedia.org/wiki/ISO/IEC_7810)).

Monocular metric depth models fail exactly where Argus works. On Booster, an indoor benchmark built around reflective and transparent materials, the share of pixels within 25 % of true depth is **46.6 % for Depth Pro, 39.4 % for Metric3D v2 and 27.6 % for UniDepth**, and Depth Anything v2 reaches 59.5 % only in a setting that is not strictly zero-shot ([Depth Pro paper](https://arxiv.org/html/2410.02073)). Depth Pro also states that it struggles with translucent surfaces, and its focal-length estimate lands within 25 % on only 64.6–84.2 % of images ([Depth Pro paper](https://arxiv.org/html/2410.02073)). Licences make matters worse: UniDepth is non-commercial and Linux-only ([UniDepth](https://github.com/lpiccinelli-eth/UniDepth)), and Depth Anything V2 Base and Large are CC BY-NC ([DA V2](https://github.com/DepthAnything/Depth-Anything-V2)). Lens metadata plus a tape-measured distance does not rescue the situation either, since 1 cm of error at 30 cm is about 3.3 % scale error, and webcams and video platforms carry no such metadata.

Established plant-science tools show that a pixel mode is no second-class option. PlantCV derives scale from the known chip size of a detected colour card, the same idea as the Argus Card ([PlantCV](https://docs.plantcv.org/en/latest/transform_detect_color_card/)); RhizoVision Explorer reports lengths and areas in pixels unless the user supplies a pixel size ([Zenodo 7825935](https://zenodo.org/records/7825935)); and ImageJ sets scale from a line drawn over a known distance ([ImageJ](https://imagej.net/ij/docs/menus/analyze.html)), exactly what Argus's ruler already does. Ratios such as area(t)/area(0) need no scale as long as the camera never moves, zooms or cuts, frames are never resized, growth does not rise toward an overhead camera (which inflates apparent area), and the frame interval is known. Registering every frame to frame 0 and flagging a scale change beyond about 1 % checks the first condition automatically. A labelled reading then looks like "Area: 412 % of first frame (pixel units; no physical reference)".

Colour follows the same logic. Global white-balance tricks miss badly on the standard benchmark, with 95th-percentile errors of **11.25° for grey-world and 19.01° for max-RGB** ([UEA benchmark](https://colour.cmp.uea.ac.uk/datasets/illuminant-estimation-errors.html)), and grey-world would invent colour change as seedlings turn green. The sound cardless approach is ΔE00 against each vessel's own start, normalised per frame by a neutral background patch whose own drift becomes the noise floor. Germination barely uses colour, so this can wait.

## Licences decide what reaches the video and the repo

The hackathon bans projects that use data or assets without the rights to them, while allowing footage recorded before the event as long as all analysis shown comes from hackathon code ([KB 01](../knowledge-base/01-hackathon-rules-and-dates.md)). CC0 and CC BY sources can be shown, analysed and committed with title, author, source and licence credited, and Creative Commons recommends putting that credit both in the video and in its description ([CC attribution practice](https://wiki.creativecommons.org/wiki/Recommended_practices_for_attribution)). CC BY-SA clips carry a catch: overlaying masks and measurements arguably makes an adaptation, so the demo video would itself need a BY-SA licence, which CC BY sources avoid. YouTube gives every upload the Standard licence unless the creator picks CC BY, and it cannot grant rights to anyone else's content ([YouTube Help](https://support.google.com/youtube/answer/2797468?hl=en)). Its Terms of Service also forbid downloading except where the service expressly allows it or with permission ([YouTube ToS](https://www.youtube.com/static?template=terms)), so even CC BY videos should come from Wikimedia Commons, which mirrors them with recorded provenance, a licence-review process and a list of channels known for mislabelling ([Commons:YouTube files](https://commons.wikimedia.org/wiki/Commons:YouTube_files)). Fair use is a last resort: there is no safe percentage, and educational intent is weighed rather than decisive ([US Copyright Office](https://www.copyright.gov/fair-use/more-info.html)).

## Conclusion

The scarce resource turned out to be experimental design, not footage. Public germination timelapses exist, but almost none combines a treatment with replicates in one frame, which means Argus's own rules on controls, replicates and preregistration are stricter than most published data can satisfy. The demo should show that friction rather than hide it: a verdict marked "retrospective re-analysis", a rival explanation naming separate runs and a reading marked "pixel units only" each display rigour that a simple image analyser cannot fake. A found dataset also beats home footage on one axis, because Genze's per-seed labels let Argus publish an accuracy figure that its own jars could never provide.

Cardless measurement is mostly bookkeeping rather than new computer vision. The geometry of a known object in the plane is decades old; the real work is recording where each scale came from, how uncertain it is, and when a ratio stops being valid. That makes the image-sequence importer with its source record the build with the longest reach: it turns Argus from a camera app into a tool that can re-analyse any published timelapse, a stronger generality claim than any single experiment.
